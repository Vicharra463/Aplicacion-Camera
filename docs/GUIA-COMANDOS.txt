============================================================
 GUIA DE COMANDOS - Servidor FTP Camara CYTV Ancon
 Para PowerShell (tambien valen en CMD don diga lo contrario)
 Instalado en: C:\CytvAncon
============================================================

------------------------------------------------------------
 1. ESTADO GENERAL
------------------------------------------------------------
  Get-Service CamaraCytvAncon
      Estado: Running (vivo) | Stopped (muerto) | Paused (NSSM
      reintentando tras fallos - mire logs\stderr.log)

  services.msc
      Buscar "Servidor FTP Camara CYTV Ancon" - clic derecho:
      Iniciar / Detener / Reiniciar / Propiedades (arranque auto)

  scripts\instalar_servicio.bat --check
      Diagnostico de solo lectura: SO, Python, servicio, puerto,
      firewall. No cambia nada.

------------------------------------------------------------
 2. ARRANCAR / PARAR / REINICIAR  (PowerShell)
------------------------------------------------------------
  Start-Service CamaraCytvAncon
  Stop-Service  CamaraCytvAncon
  Restart-Service CamaraCytvAncon

  En CMD equivalen a:
  net start CamaraCytvAncon
  net stop  CamaraCytvAncon

  El servicio arranca SOLO al prender la PC (aunque nadie
  inicie sesion) y si el programa muere, NSSM lo revive.

------------------------------------------------------------
 3. VER SI EL FTP ESTA ABIERTO (puerto 2121)
------------------------------------------------------------
  netstat -ano | findstr ":2121"
      Busque la linea ... LISTENING  <PID>
      (en Windows 10/11 tambien vale:
       Get-NetTCPConnection -LocalPort 2121 -State Listen)

  Probar desde la misma PC:
      ftp 127.0.0.1 2121
      usuario/password = los de config.ini (ver INFO_CAMARA.txt
      local; NUNCA se publican en el repo). Debe responder el banner del
      servidor. Salir: bye

  Desde otra PC de la red:
      ftp <IP-DE-ESTA-PC> 2121
      La IP actual la ve en C:\CytvAncon\INFO_CAMARA.txt
      (se regenera en cada arranque del servicio).

------------------------------------------------------------
 4. LOGS (donde mirar todo)
------------------------------------------------------------
  C:\CytvAncon\logs\servidor.log    - log principal en espanol
  C:\CytvAncon\logs\stderr.log      - errores de arranque python
  C:\CytvAncon\logs\stdout.log      - salida estandar
  C:\CytvAncon\instalacion.log      - del ultimo instalador

  Cola en vivo (Ctrl+C para salir):
      Get-Content C:\CytvAncon\logs\servidor.log -Wait -Tail 20

  Ultimas lineas:
      Get-Content C:\CytvAncon\logs\servidor.log -Tail 30

  Buscar algo:
      Select-String -Path C:\CytvAncon\logs\servidor.log -Pattern "placa"

  Que se ve en el log al arrancar bien:
      "Carpeta verificada/CREADA (...): C:\CytvAncon\..."
      "Modelo verificado: C:\CytvAncon\modelo\placas.onnx"
      "OCR cargado (RapidOCR ONNX, CPU)"
      "starting FTP server on 0.0.0.0:2121"

------------------------------------------------------------
 5. CONFIGURACION (config.ini)
------------------------------------------------------------
  scripts\instalar_servicio.bat config
      Muestra el config.ini completo

  scripts\instalar_servicio.bat config set CLAVE VALOR
      Cambia un valor y reinicia el servicio solo.
      Ejemplos:
        scripts\instalar_servicio.bat config set password OtraClave
        scripts\instalar_servicio.bat config set puerto 2121
        scripts\instalar_servicio.bat config set usuario camara

  scripts\instalar_servicio.bat config editar
      Abre config.ini en el Bloc de notas

  Claves principales:
    [ftp]      puerto, usuario, password, puertos_pasivos
    [worker]   cooldown_segundos, umbral_diferencia
    [filtros]  modo_descarte (eliminar|retener), umbral_modelo,
               ocr_requerido, umbral_nitidez, umbral_dedup_dist
    [rutas]    SIEMPRE rutas absolutas C:\CytvAncon\...

  Cambio manual + reinicio:
      Editar C:\CytvAncon\config.ini y luego:
      Restart-Service CamaraCytvAncon

------------------------------------------------------------
 6. DONDE ESTAN LAS IMAGENES  (nomenclatura por placa)
------------------------------------------------------------
  C:\CytvAncon\ftp_recibidos\
      Lo que sube la camara (temporal, ya procesado)

  C:\CytvAncon\imagenes_procesadas\placa\<AAAA-MM-DD>\
      Vista TELE (canal 02) - el archivo SE LLAMA COMO LA PLACA:
        CBN-449.jpg   (+ CBN-449.txt etiqueta YOLO)
      Si el OCR no pudo leer, conserva el nombre por hora:
        placa_16-32-28_107.jpg

  C:\CytvAncon\imagenes_procesadas\vehiculo\<AAAA-MM-DD>\
      Vista PANORAMICA (canal 01) - nomenclatura:
        placa-panoramica_CBN-449.jpg   (+ .txt YOLO)
      Sin lectura: vehiculo_16-32-28_107.jpg

  C:\CytvAncon\reportes\
      placas-<AAAA-MM-DD>.json  - UN ARCHIVO POR DIA con todas las
      placas detectadas: texto, primera/ultima hora, confianza y las
      rutas ABSOLUTAS de la foto de placa y de la panoramica.
      Se genera y refresca SOLO con cada placa guardada; a medianoche
      se cierra el dia anterior; al reiniciar el servicio se actualiza.
      Ejemplo de entrada:
        {"placa": "CBN-449", "primera_vez": "2026-11-11T17:20:45",
         "confianza_max": 0.90,
         "imagenes": {"placa": ["...\\placa\\...\\CBN-449.jpg"],
                      "panoramica": ["...\\vehiculo\\...\\placa-panoramica_CBN-449.jpg"]}}
      Consumible desde PowerShell:
        Get-Content C:\CytvAncon\reportes\placas-2026-11-11.json -Raw |
          ConvertFrom-Json | ForEach-Object { $_.placas.placa }

  C:\CytvAncon\registro.db
      Base SQLite: placas vistas por dia (dedup). Si quiere
      que una placa se vuelva a guardar, borre su fila de
      ahi o borre el archivo (se recrea vacio).

  C:\CytvAncon\descartadas\
      Solo si modo_descarte = retener

------------------------------------------------------------
 7. REINSTALAR / ACTUALIZAR EN ESTA MISMA MAQUINA
------------------------------------------------------------
  1. Stop-Service CamaraCytvAncon
  2. Copiar los archivos nuevos encima de C:\CytvAncon
  3. Doble clic scripts\instalar_servicio.bat (o powershell:
     powershell -ExecutionPolicy Bypass -File C:\CytvAncon\scripts\instalar.ps1)
  4. El instalador es idempotente: reutiliza venv y Python
     si ya estan bien.

  En OTRA maquina: copiar la carpeta del proyecto a cualquier
  lado y correr scripts\instalar_servicio.bat (ver GUIA del bundle).

------------------------------------------------------------
 8. SI ALGO FALLA - ORDEN DE REVISION
------------------------------------------------------------
  1. Get-Service CamaraCytvAncon          -> estado
  2. Get-Content C:\CytvAncon\logs\stderr.log -Tail 20
  3. Get-Content C:\CytvAncon\logs\servidor.log -Tail 30
  4. netstat -ano | findstr ":2121"       -> ocupado por quien
  5. Get-WinEvent -FilterHashtable @{LogName='System'; StartTime=(Get-Date).AddHours(-1)} |
        Where-Object { $_.Message -match 'CamaraCytvAncon' }
     (eventos 7000/7024/7031/7034 del servicio)

  Significados comunes:
    - Paused + "no tiene acceso al archivo" en stderr:
      un .exe del servicio quedo dentro de C:\Users...
      (nunca ponga el servicio ahi; todo va en C:\CytvAncon)
    - WinError 10048 / "direccion de socket en uso":
      dos servidores peleando por 2121 - solo debe haber uno.
    - Servicio Running pero la camara no sube:
      revise la IP en INFO_CAMARA.txt y que la camara
      apunte a ESA IP (su PC cambia de IP si no tiene
      reserva DHCP en el router - hagala).

------------------------------------------------------------
 9. REGLAS DE ORO
------------------------------------------------------------
  - NO correr scripts\instalar_servicio.bat de copias viejas
    (Escritorio u otra carpeta): re-apuntarian el servicio.
  - NO mover C:\CytvAncon con el servicio corriendo.
  - NO poner rutas relativas en config.ini.
  - Puerto 2121 = UN servidor. Para migrar: parar el viejo
    y recien ahi arrancar el nuevo.
  - La camara apunta a la IP de INFO_CAMARA.txt; si la PC
    no tiene reserva DHCP, esa IP puede cambiar.
